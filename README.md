
# Habit Tracker

## Project Description

Habit Tracker is a web application built with Python and Streamlit to help users build positive habits, stay consistent, and monitor their daily and weekly progress.

The application allows users to manage their habits, record completions, track streaks, and stay motivated through a reward system.

## Features

- **Add Habits:** Create new habits with daily or weekly frequencies and set target goals.
- **Log Habit:** Record completed habits and track daily activities.
- **Manage Habits:** View and manage your existing habits.
- **My Progress:** Monitor daily progress, completion rates, and current streaks through charts and statistics.
- **Completion History:** Visualize habit completion records over time.
- **My Rewards:** Earn points and unlock rewards by maintaining consistency.

## Technologies Used

- Python
- Streamlit
- Pandas
